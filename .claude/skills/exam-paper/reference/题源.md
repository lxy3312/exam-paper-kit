# 题源

## 哪个题位最难（北京卷）

| 题位 | 一般考什么 |
|---|---|
| 选择第 8 题 | 多结论判断：二次函数图象信息、旋转或圆里的动态问题 |
| 填空第 15、16 题 | 最值、推理（方案/分配/游戏）、新定义小题 |
| 解答第 24 题 | 圆：证切线＋求线段 |
| 解答第 25 题 | 函数建模、实际问题（喷泉、投篮、桌面拼接）、表格探究 |
| 解答第 26 题 | 二次函数含参：比大小、区间最值、对任意 x 都成立求范围 |
| 解答第 27 题 | 几何综合：含参旋转，特殊位置→一般位置，写等量关系并证明 |
| 解答第 28 题 | 新定义（关联点、对称点、张角点……），最后一问求范围 |

「超难」卷就从这些位置里挑。期中卷的 27、28 题最容易被以前的卷子用掉，可以补区一模、二模的同位题（只要知识点在范围内）。

## 去哪儿找

- 名校期中、期末卷（对口最好）、各区一模二模、中考真题、按章节整理的真题汇编。
- 有文字层的 PDF 可以 `page.get_text()` 定位、对答案；公式在文字层里是打散的，题干要看图抄。
- 扫描件、截图：`scripts/crop.py` 先整页小图找位置，再高分辨率裁那一道。
- 低清的汇编图（几百像素宽）只用来对答案，别从上面抄公式；放大了读，闭区间开区间、正负号最容易看错。

## 怎么标

- 卷面：题号后面括号写出处，例「（北京四中2024—2025学年初三上期中第16题）」。`used_sources.py` 靠这个格式统计用过的题。
- 答案页：每道写来源（学校参考答案／区评分参考／解析版／自己解的），自己解的要在 verify 里验算过。
- 原卷文件不放进公开仓库。
