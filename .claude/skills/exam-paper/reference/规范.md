# 卷面规矩（交付前对照）

这些是给一个对排版很挑剔的学生出卷时一条条攒下来的，违反了学生会直接跳过这道题。换了学生，按新学生的要求增删。

## 版面

- [ ] A4 整页两栏，题目和作答区一起竖着排（不要把一个横向作答框切成左右两半）。
- [ ] 作答区**只留白，不画线、不画框**（按分值折算留白，或者给行数）。
- [ ] 正文宋体，标题黑体；上下标用 `<super>`/`<sub>`；字体缺字形的符号不用（`lint_markup.py` 会查）。
- [ ] 分式是真分数线、根号盖住整个被开方式（源码写 ÷ 和 √，自动转）；卷面不出现 `/` 和 `^`。
- [ ] 数字和单位不空格（20m）。选择题选项用表格对齐。
- [ ] 题干和选项、题干和要看的图**不拆开**；只有备用图可以单独流到下一栏。宁愿留空也不拆。
- [ ] 但也不能空一大片：题目区栏底的大空白要处理（调顺序／补备用图／挂提示）。
- [ ] 标点不放行首。
- [ ] 答案和试卷分成两个文件；需要的话每页加水印。

## 图

- [ ] 涉及图形的题必须配图——没图学生会整题跳过。
- [ ] 几何压轴：图1 给第(1)问、图2 给第(2)问、外加一张备用图。
- [ ] 图要大，能在上面画辅助线。
- [ ] 点按题干条件算出来，画完逐条核；练习题的图不画答案点。

## 题

- [ ] 要难、要精，基础和拓展都覆盖；「超难」就是每个题位挑最难的。
- [ ] 原题题干照抄、标出处；原创的注明，不冒充真题。
- [ ] 北京 27 题的骨架：含参角 α → 旋转一个和 α 有关的角 → (1) 特殊位置证明 → (2) 一般位置「用等式表示数量关系并证明」。
      28 题是新定义，最后一问求取值范围。
- [ ] 有错题档案就对着出（比如开方丢整体、不舍根、把 m+n=1 当成 m²+n²=1）；学生已经稳的题型别再出。
- [ ] 答案页写清来源：官方答案／解析版（程序复核一致）／自己解的。所有数值答案都程序核算过。

## 交流

- [ ] 直接给东西，不写学习计划和客套话。
- [ ] 用户只是评价风格时，不等于授权改别的文件；没让改的旧卷子别动。
- [ ] 不画、不放任何现成作品的人物或漫画（版权）。
