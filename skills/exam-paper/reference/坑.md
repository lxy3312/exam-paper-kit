# 技术上的坑（都踩过）

## 环境

- Windows 控制台打印中文要 `PYTHONIOENCODING=utf-8`，不然 gbk 报错。
- 依赖只有 reportlab、pymupdf、pillow；别顺手引入 numpy（拟合抛物线自己写三点公式）。
- 字体默认用 Windows 的宋体/黑体/微软雅黑/幼圆；别的系统用环境变量 `EXAM_PAPER_FONT_BODY`、`EXAM_PAPER_FONT_HEAD` 指到 TrueType 轮廓的中文字体。
- 改脚本里带中文、反斜杠、`\n` 的字符串，**写一个 .py 补丁文件再跑**，别在 heredoc 里内联（`\n` 会变成真换行、`\d` 会报警告）。
  补丁里每处替换都 `assert old in s`，对不上就停，别静默失败。
- 渲染图、临时 PDF、补丁脚本放临时目录，别混进交付目录。

## 公式（layout._markup 自动把 A÷B、√X 画成真分数线/真根号）

- √ 会吞后面紧跟的字母、数字、括号组：`√2AF`→√(2AF)，`√3x`→√(3x)，`√3(R+r)`→√(3(R+r))，`1+√3（三帆解析）` 把括号也开方。
  写 `√(2)AF`、`√(3)x`、`√(3)×(R+r)`，出处标签挪到答案前面。
- ÷ 同理：`9√3÷5m（约3.12m）` 分母变成「5m（约3.12m）」；`27÷8（…）` 同。断句或换写法。
- ÷ 左操作数会往前吞：`（6分）（1）π(R²-r²)÷6` 整段进了分子。前面加几个汉字（「一个扇环的面积是π(R²-r²)÷6」）。
- 根号里不能套分式（`√(4+2÷a)`），换元。操作数里有 `<sub>`/`<super>` 的、后面紧跟 `%` 的不会自动转，要手写。
- 宋体缺字形：⇒ ⇔ ⊂ ⊆ ⟺ ↔ ∉ ✓ ⅓ ⅔ 下标数字 ᵢ，上标只有 ¹²³。用 `<super>4</super>`、`<sub>1</sub>`。
- `lint_markup.py` 能拦住上面大部分。

## 断行

- `P.setup()` 打开禁则：全角「，；：？！）」等和「·」不放行首，内联公式图不挂行尾（会改 ReportLab 的全局表，同一进程里别的文档也受影响）。
- 只能挂一个字符：「）。」「”；」「），」连着出现时第二个还是会掉到行首——改措辞，多一个字少一个字就挪开了。
- 填空横线写全角「＿」，`K.blanks()` 换成半角下划线（全角会被拆成两行）；横线太长会剩个尾巴到下一行，缩短。
- 小问用 `\n` 分段（SUBQ 样式），别用 `<br/>`（写满一行时多空一行）。

## 排版

- `FitBlock`：不拆的整块，放不下先把图缩到 0.78 再整块换栏。**不能嵌套 KeepTogether**（外层会认为永远放不下）。
- 作答留白是 `Gap`（高度在 spaceBefore 里），落到栏首自动消失。末尾不要裸 `PageBreak`。
- `CondPageBreak` 在两栏里是「按栏」换。关卡头前面自带一个。
- 首页两栏比后面矮 50mm（横幅位）。答案文件 `build_doc(..., banner=False)` 第一页不留横幅位。
- 图注「第N题」由 qb 按卷面题号改写，`figs` 里写什么数字都行。
- 一整块超过 20cm 的长题（5 张图那种），用 `groups` 按小问切块。

## 画图

- `PolyLine` 不接受 `fillColor`；`Card` 会把图转成灰度（MONO）。
- `geometry.lbl` 支持 `B<sub>1</sub>`（String 本身不认标记）。
- 标签位置用 `dx, dy`（mm，不随缩放），圆上的点用「圆心→点」方向往外推（`figkit.label_out`）。
- 画完一定对着题干逐条核：「左上角共线」画成连到右上角这种错，学生一眼就看出来。

## 读原卷

- 文字层 PDF：`page.get_text()` 能抽，但公式是打散的（`45 DBM ABM`），只拿来定位和对答案，题干看图抄。
- 扫描件：`crop.py` 裁出来直接看图。别说「提取不到」。
- 低清汇编图不抄公式，只对答案；放大读，别把闭区间看成开区间。
